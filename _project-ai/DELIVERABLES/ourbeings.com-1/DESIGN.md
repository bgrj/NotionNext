# 子页面设计约定

参考：[不过人间 · 释哲](https://shizhe-buguo-renjian.stonycake21.chatgpt.site/)。已核对当前第 1 版页面源文件与托管元数据；本轮没有新建或修改该参考站。

## 共通方向

保留 Our beings 现有金色与手部意象。内页吸收参考站的纸张质感、衬线标题、克制的墨绿、细线分隔、书刊式留白与可长时间阅读的正文。色块和插画只用于帮助辨识内容，不新增整屏装饰或重做首页。

| 元素 | 约定 | 用途 |
| --- | --- | --- |
| 页面纸色 | `#f5f2e9`，内容面 `#fffdf8` | 阅读面与表单 |
| 主文字／次文字 | `#302a23`／`#655e54` | 保持阅读对比度 |
| 墨绿点缀 | `#314b3e` | 当前筛选、馆藏眉题与轻量行动 |
| 原金色 | 沿用站点主题，局部参考 `#785620` | 细线、链接与身份流程 |
| 标题 | 系统宋体／衬线回退；不新增远程大字体依赖 | 中文书刊感 |
| 正文 | 16～18 CSS px，行距 1.8～2.1，阅读宽约 40～44rem | 长文、日记与说明 |
| 控件 | 主操作至少 44 × 44 CSS px；清晰焦点 | 手机与键盘 |
| 深色 | 同一结构使用深纸色与浅文字 | 不对用户图片统一加滤镜 |

颜色为分项设计值，不批量替换全站 CSS。先在当前组件作用域验证，再复用已验收的样式。

## 保护范围与验收

首页上下手图、四区字形、位置比例、入口分区与金色连线均为保护范围。局部组件不得通过全局选择器改变这些元素。

每项 UI 至少核对：空／加载／保存中／成功／失败／离线提示，390 CSS px 与桌面宽度，键盘焦点，深色模式，减少动效。截图或浏览器无法执行时明确标注未验收，不以源码尺寸推断真实浏览器表现。

参考站中的试刊文章、个人简介、收藏行为与插画不自动复制为用户正式内容。原收藏仅在浏览器保存的事实，也不迁移为本站的云端用户数据。
