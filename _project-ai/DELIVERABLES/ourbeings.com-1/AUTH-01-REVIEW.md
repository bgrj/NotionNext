## 本项行为

| 场景 | 候选行为 | 验证边界 |
| --- | --- | --- |
| 访客进入私人空间 | 分别提供登录、注册，目标返回自己的空间 | 真实组件替身测试通过 |
| 从一篇内容进入登录 | 菜单保留验证后的站内返回地址 | 返回路径与原生组件参数测试通过 |
| 注册／验证码／恢复／MFA | 沿用当前 Clerk 原生安全步骤、路径路由和跨登录注册参数 | 参数衔接通过；未向真实邮箱发送验证码或重置请求 |
| 已登录打开登录页 | 提供继续访问、我的空间、切换账号 | 替身状态测试通过 |
| 加载较慢 | 12 秒后给出刷新重试与公开阅读路径，不假定已登录 | 定时器与未发起私人请求验证通过 |
| 登录未开放 | 明确说明，不调用 Clerk hook 或私人接口 | 配置关闭测试通过 |
| 退出登录 | 防重复点击、等待、失败可重试；成功返回登录并在访客状态下给出已退出反馈 | SDK 替身测试通过，未验证真实会话失效 |
| A 切换到 B | 重新挂载全部私人工作台状态，清空 A 未保存输入，忽略 A 迟到响应 | 两项回归：基线失败，候选通过 |
| 保存时断网 | 保留当前输入并给出可重试错误，不产生未处理拒绝 | 网络替身测试通过；默认私密未改变 |
| 从认证流程浏览公开页 | 普通链接不继续携带 returnTo、redirect_url、Clerk ticket 等认证参数 | 两条原生步骤路径回归通过 |
| 子页面视觉 | 局部衬线标题、墨绿眉题、纸色与原金色；认证页标题和 noindex | 组件编译通过；浏览器外观与手机截图未验收 |

`noindex` 仅控制索引意图，不替代服务端授权。账号状态隔离只解决客户端残留；API、附件、检索和真实两用户越权仍需 OB1-02／03 验收。
