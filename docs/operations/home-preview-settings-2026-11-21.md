# 四板块展示与阅读设置

本次调整接续同日的「首页暂时仅开放道」版本：四块书法全部显示，内容入口仅开放「道」。

## 实施计划与结果

1. 把板块是否显示与是否开放分别配置，保留背景、书法及原点击区域。
2. 电脑悬停或键盘聚焦后显示临时指引；鼠标点击「道」进入文章。
3. 手机首次点按在主视觉下方展示独立预览，点击阅读或再次点按「道」进入；其他三个板块提示「开发中……」。
4. 网站设置分为板块导航、阅读偏好、站点信息及账户。电脑为右侧面板，手机为可滚动底部面板。支持浅色、深色及恢复站点默认；语言与外观偏好保存在本机。
5. 站点信息使用 Notion 已发布公共菜单，遵守 CUSTOM_MENU；草稿、隐藏菜单及后台配置不显示。部分板块开放期间不显示归档、全部分类、标签及搜索的聚合入口。
6. 同步 Notion 配置与说明，验证交互、构建后推送 ourbeings.com 分支，由 Vercel ourbeing 项目发布。

## Notion 配置

| 配置名 | 当前值 | 含义 |
| --- | --- | --- |
| OURBEINGS_HOME_SECTIONS | our,self,dao,shu | 首页和设置中可见的板块 |
| OURBEINGS_OPEN_SECTIONS | dao | 可进入文章的板块 |
| APPEARANCE | auto | 默认跟随系统；访客可恢复此默认 |

「道」系列继续读取 18 篇已发布文章。配置中心保留原表结构及其他设置，并补充首页交互和「网站配置」菜单的维护说明。

## 验证记录

- 交互、设置、文章布局及发布状态相关 48 项测试通过，覆盖预览、点按进入、未开放入口、菜单过滤、语言和外观选择。
- 本地完整构建在类型检查阶段因系统资源不足终止，新 PowerShell 启动同时报告 0x800705af；不能视为构建通过。正式完整构建由 Vercel 执行。
- 本地完整 ESLint 复查也受内存限制，512MB 堆上限不足，1024MB 进程启动失败；未把这两次尝试记为通过。
- 发布后核验桌面悬停、手机触控、320px 窄屏设置、偏好持久化、道系列分页及正文。
- 首轮正式站触控检查发现顶栏的 backdrop-filter 使手机固定面板相对顶栏定位。手机打开设置期间关闭此滤镜，使面板按视口定位；移除无可用子项的 `/#` 菜单占位链接。

仅控制导航入口，不改变其他文章原有发布状态或访问权限。三个既有未跟踪的 beings API 文件不纳入此次提交。
