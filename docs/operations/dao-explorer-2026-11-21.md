# 「道」栏目：卡片轮换与检索方案

## 目标与范围

- 改造 `my-theme` 下的 `/category/道`，保留现有站点顶栏、页脚、上手背景与文章地址。参考求是网的封面轮播布局，但不复制其红色品牌或标识。
- 桌面端三张文章卡片分布在上手周围，当前卡片位于前景；按顺序循环切换。窄屏采用较紧凑的卡片布局。
- 不改动其他分类、文章状态、数据库内容及现有站点设置。

## 数据与访问边界

- 沿用分类页的数据获取、缓存和 ISR；仅取 `category=道`、`type=Post`、`status=Published`。
- 在分页切片之前，通过现有 `cleanPostSummaries` 生成公开摘要，交给新界面，确保搜索和列表覆盖全部符合条件的文章，而不是仅覆盖当前分页。旧分页地址也使用相同完整列表。
- 卡片与列表沿用现有 `href`；保护文章仍通过原有文章访问控制处理。列表不传正文、密码或 block map。
- 未填写封面时使用朴素文字封面；无文章时显示空状态。背景沿用配置中心 `OURBEINGS_ARTICLE_BACKGROUND` 的安全校验和默认值。

## 交互

- 自动每 7 秒前进一张，切换有缓动过渡；可点击左右卡片或左右箭头，点击中央卡片进入文章。
- 鼠标悬停、键盘焦点、打开列表或搜索时暂停；可显式暂停／继续。系统开启减少动态效果时停止自动轮换并取消过渡。
- 「文章列表」展示全部匹配文章，每次先显示 12 篇、按需加载更多。搜索针对标题、摘要、标签和显示日期，不是全文搜索；无匹配时显示提示。
- 按钮和搜索框提供标签与焦点样式；移动端检查首屏、列表、搜索和横向溢出。

## 验证与发布

1. 运行组件测试，检查轮换、暂停、减动态、列表、搜索及空状态；运行相关布局回归测试。
2. 以实际公开数据进行桌面与手机预览，检查封面、链接、检索、文字可读性和边界。
3. 执行 `yarn build`，将变更提交至 `ourbeings.com` 分支。Vercel 的生产站点部署需以该提交的部署状态和线上页面检查结果为准。
4. 如需回退，使用 Git 回退本次提交，再确认 Vercel 的新部署完成；不需要修改 Notion 文章数据。
